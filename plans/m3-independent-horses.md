# Milestone 3: Independent Horse Ownership, Saddlebag/Tack Persistence, Host Parking & Tack Sync, Far Whistle, and Quest Horse Gating

## Architecture Overview

Milestone 3 gives every co-op player independent horse ownership, persistent personal saddlebag & tack inventories across `.whs` saves and `.hblk` snapshots, stationary dismount parking and visual tack sync on the Host without polluting Host saves, reliable cross-region whistling, and quest/trader horse-grant isolation:

1. **Per-Player Horse Companion & Saddlebag/Tack Save Splicer (`dotnet/KcdMp.Client/WhsSave.M3Horse.cs`)**:
   - Registers `M3HorseSaveExtension` (`WhsSave.ISaveExtension`, `Order => 10`) via `[ModuleInitializer]` without modifying `WhsSave.cs` or `WhsSave.Wo125.cs`.
   - Parses `01f4/01f8/7308/3529/1160` (`CompanionBlock`), supporting real empty payloads (`Len == 0`), `WhsSaveTests`'s synthetic 4-byte `00 00 00 00` placeholder (left untouched when no `0x0DD6` horse link exists so all existing save tests stay byte-identical), and real `0x0DD6` 36-byte TLV companion links (`[u16 0x0501][16B masterSoulGuid][u16 0x0501][16B companionSoulGuid]`).
   - Distinguishes horse souls in `01f4/01f8/7308/3529/1161` from Mutt (`tvez_vorech`, shared GUID `44a28861-719d-9fed-e3dd-b20c479e8781`), wild/town dogs, and wolves, and preserves Mutt plus all NPC companion links (`master != HenrySoul`).
   - Stores `"horse_companion"` in `HenryParts.Extensions`: `[0]` when Joiner owns no horse in a real save, or `[1][16B companionSoulGuid][i32 soulNodeLen][full 0x115E horse soul node]` when Joiner owns a horse.
   - Includes Joiner's horse `0x1301/0x0007` item `instanceGuid`s in `henryOwnedItemIds` and Host's owned horse item `instanceGuid`s in `hostPrivateItemIds` so dynamic `0x05AD` keys stored in saddlebags round-trip cleanly in `01f4/01f8/7302/000B`.
   - Rebuilds `1160` for Joiner's spliced save (removing Host's Henry->Horse link when Joiner owns no horse or a different horse, and appending Joiner's Henry->Horse link when present in `hostRaw`) and splices Joiner's horse `0x1301` (with `qclasses` quest items stripped from `0x0007` and cleaned from `0x0001`/`0x0006` equipped slots) and `0x12FB` onto `currentSoulNodeBytes` while preserving Host's `0x12F9` entity binding and `0x12FF` reputation field for clean composition with Milestone 4 (`Order => 20`).

2. **Quest Horse Assignment Gating & Extended Native Entity Names (`native/KCDMP/wo200_rules.h`, `wo200.cpp`, `wo139_rules.h`, `wo139.cpp`, `wo216.cpp`, `hits.cpp`)**:
   - Adds `Method::PlayerHorse` (`ReplacePlayerHorse`, `SetPlayerHorse`, `ClearPlayerHorse`) and `"Kill"` under `Method::Damage` in `wo200_rules.h`, plus `is_horse_dispose_parent` (`replaceplayerhorse` / `disposeold`) in `wo200_rules.h` & `wo200.cpp` so quest/trader horse grants and old-horse disposal (`replaceplayerhorse_disposeoldifexists`) route to `Verdict::TalkerOnlyHost` during Host `OutPortReplay` closures and `Verdict::TalkerOnlyJoiner` / `Verdict::PuppetRefused` on Joiners.
   - Adds `wo139rules::is_entity_name` (`1..120` chars, `[A-Za-z0-9_\[\]/\-:]`, rejecting `//`) for `wo139` `kOpContext`, widens `hits::find_name_visit` to `char buf[128]`, and raises `wo216` `kOpOutfitOf` / `kOpExempt` / `b_actions` buffers so 65-char bracketed Trosky horse entity names (`horse[animalcare/horseCare6_<guid>]`) resolve in `hits::eid_of_name`, `WO-216 B` (`no_brains`) exemptions, and live soul equipment reads.

3. **Bracketed Horse Names, Agent Horse Protocol & Live Tack Polling (`M3HorseRules.cs`, `GameBridge.M3Horse.cs`, `Protocol.cs`, `CombatPipe.cs`, `GameBridge.Wo136.cs`, `GameBridge.Wo137.cs`, `GameBridge.Wo178.cs`, `GameBridge.Wo216.cs`)**:
   - Raises `Protocol.MaxHorseNameLen` to `120` and validates horse entity names (`1..120` chars, `[A-Za-z0-9_][A-Za-z0-9_\[\]/\-:]*`, rejecting `//`, quotes, spaces, control chars, and `kcd2mp_` prefixes) across `HorseInfoUp`/`HorseInfoDown`, `w160_ownhorse`/`QuestAskOwnHorse`, `w136_ride`, `w154_ride`, `w216_exempt`, and `Wo139ContextAsync`, while also mapping `WO-217 B.3` `lhXXXXXXXX` stream aliases (`>= 60` chars) so Joiner's companion horse is never driven under its alias.
   - Seeds Joiner's `_m3JoinerHorseName` + tack from `.hblk` `horse_companion` (`0x12F9` + `0x1301`) on Join/Rejoin (`KCD2MP_M3SeedOwnHorse`), preserves `ownHorse` across unstreamed layers (`GetHorseId() == 0` / `GetEntity(id) == nil`), serializes & retries `crime_ignoredHorseTheft_Horse` on Host without modifying saved `mountIsLegal`, strips/restores temporary peer tack around both mod and native Host saves (with `15 s` safety timeout and `"busy"` guard), and releases peer horses on disconnect.

4. **Host Horse Dismount Parking, Legality Exclusion, Multi-Owner Collision Proxy & Visual Tack Sync (`kdcmp/Data/Scripts/Startup/kdcmp.lua`)**:
   - Excludes Host's personal owned horse (`player.player:GetHorseId()`) and all peer-owned horses from `KCD2MP_W139HostHorses()` so personal horses are not broadcast as free-for-all mounts.
   - Keeps Joiner-owned world horses (`name ~= hostOwnHorse`) paused (`wh_ai_PauseNPC`) at Joiner's dismount spot on Host instead of resuming trader schedules that walk them back to Semine/Nomad Camp, leaves `mountIsLegal` untouched on Host (relying solely on runtime `crime_ignoredHorseTheft_Horse` for Joiner's `ForceMount`), and restores original state when switched or disconnected.
   - Protects Host's own horse and handles multi-joiner same-horse collisions by spawning/maintaining a dedicated `NO_SAVE` `kcd2mp_peerhorse_<peer>` proxy per colliding peer, swapping cleanly when `HorseInfoDown` arrives after `isRiding`.
   - Applies Joiner's equipped tack classes (`CreateItem` + `EquipInventoryItem`) onto Joiner's world horse or `NO_SAVE` proxy on Host while tracking every mod-created handle and stripping/restoring around Host saves so Host `.whs` saves stay clean.

5. **Permanent Joiner Stream Hold & Far Whistle Across Regions/Unloaded Layers (`kdcmp/Data/Scripts/Startup/kdcmp.lua`, `GameBridge.M3Horse.cs`)**:
   - Permanently suppresses Joiner's own companion horse (and its `WO-217` `lhXXXXXXXX` alias) from Host's `NpcState` / `NpcRoute` stream while owned on Joiner (`Wo136DropRidden` + `m3OwnHorseStreamHold`) and keeps it exempt from `WO-216 B` (`no_brains`), so native `CallHorse` and post-dismount parking are never yanked back by Host.
   - On Host (`KCD2MP_W160Whistle`), queues `w.pendingFetch[src]` when Joiner's avatar is `> 150 m` from Host (`WO-157` physics range guard) for automatic placement once in range, and spawns/moves `NO_SAVE` stand-in `kcd2mp_peerhorse_<src>` 7 m beside Joiner's avatar when `<= 150 m` and `Horse B`'s level layer is unstreamed or collided.
